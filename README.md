# Аделя Ахмадиева — портфолио

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

Дизайн адаптирован по мотивам DENTIS (https://manath-iq.github.io/stomatologiya/) и manath (https://manath.site/): светлая основа, тёмные блоки, лаймовый акцент, плавающее меню и сетка работ.

- Все 6 проектов и интерактивные демо сохранены.
- RU/EN переключается в шапке и запоминается в браузере.
- На мобильных устройствах навигация открывается круглой кнопкой меню.
- Демо открывается по нажатию на превью. Стрелки переключают проекты, Escape закрывает просмотр.
- Шрифты хранятся локально в `assets/fonts`.

Контент и список работ: `index.html`, `script.js`. Оформление: `styles.css`. Демо: `demos/`.
